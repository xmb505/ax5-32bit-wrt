AX5-32Bit v14.3 release
======================

**⚠️ 这是手工拼出来的镜像,不是 OpenWrt `make` 编译产物。**

不要指望 clone + `cd src && make` 能产出这个 `.ubi`。
这是从 v13.9 (NWRT QSDK 12.2 factory rootfs + 4KB-剥离 kernel FIT) 为基线,
手工叠加以下现代化组件后拼出来的:

  - dropbear v2026.94 + baked RSA-2048 host key (首启 SSH 不会 reset)
  - LuCI git-26.232 (2026 mainline, 模块化架构 + JS 视图)
  - libustream-ssl + libmbedtls 2.16.12 (让 uhttpd 走 TLS via mbedtls, 不再裸 HTTP)
  - ECDSA P-256 server cert (CN=AX5-<last 6 MAC>, SAN: 192.168.1.1, openwrt.lan, xiaomi.router, 127.0.0.1, 825天)
  - /etc/config/system: timezone Asia/Shanghai + 5 个 NTP server
    (0.pool/1.pool/cn.pool/ntp.aliyun/time1.cloud.tencent)
  - sysntpd 默认 enabled (busybox ntpd)
  - root 密码 'password ' (SHA-512 hash 进 /etc/shadow)
  - 内核 FIT 与 v13.9/v14.0/v14.2 byte-identical (Secure Boot 签名, NWRT 5.4.213)

详细拼装步骤、坑、修法都在 ../doc/ 里:

  - ../doc/NWRT_FACTORY_REFERENCE.md - 整个手工拼装流程
  - ../doc/NWRT_WIFI_BOOT_FLOW.md - NWRT boot 序列分析
  - ../doc/WIFI_IMPLEMENTATION.md - WiFi 配置 + debug
  - ../doc/INCIDENT_2026-08-20.md - 调试事故复盘
  - ../doc/INCIDENT_2026-08-21_QODER_V142.md - qoder v14.2 接力复盘

要重新做一版不一样的,看 CUSTOMIZE.md (快速自定义) 或
NWRT_FACTORY_REFERENCE.md §6 (深度修补清单)。

## 上手步骤

1. **正常烧写 (sys1 → sys2 + 切 sys2):**
   ```
   cd release/
   ./build.sh
   # 烧完后等 60-90s 让 sys2 启动
   ssh root@192.168.1.1
   #   root 密码: password
   ```

2. **uhttpd/HTTPS 验证:**
   ```
   # HTTP 应自动 307 重定向到 HTTPS
   curl -I http://192.168.1.1:81/

   # HTTPS 应工作 (self-signed, -k 跳过 cert 校验)
   curl -kI https://192.168.1.1:443/

   # Cert 信息 (ECDSA P-256 + SAN + 825d)
   echo | openssl s_client -connect 192.168.1.1:443 -servername openwrt.lan 2>/dev/null | \
       openssl x509 -noout -subject -dates -ext subjectAltName,extendedKeyUsage
   ```

3. **NTP 验证:**
   ```
   date                          # 应显示 CST-8 时区
   ps | grep ntpd                # busybox ntpd 应在跑
   /etc/init.d/sysntpd status    # enabled
   ```

4. **紧急 TFTP 救援:**
   ```
   # 串口接上, U-Boot 提示符下跑 release/flash-via-tftp.sh 输出的命令
   ```
