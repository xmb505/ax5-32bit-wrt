AX5-32Bit v21.0 release (实机验证通过, 2026-08-26)
============================================

**⚠️ 这是手工拼出来的镜像,不是 OpenWrt `make` 编译产物。**

不要指望 clone + `cd src && make` 能产出这个 `.ubi`。
这是从 v20.6 (NWRT QSDK 12.2 factory rootfs + 4KB-剥离 kernel FIT) 为基线,
外科手术式替换了 `haku_wrt` 二进制和 `config.json`,其他 3173 个文件全部继承 v20.6。

v21.0 改动 = 仅 2 个文件:
  - /usr/bin/haku_wrt: ver1.0.20 (7,667,896 B, git d15527f) → ver1.1.2 (8,519,864 B, git 73a05e8)
  - /etc/morden_web/config.json: ver1.0.20 (32 字段) → ver1.1.2 (43 字段, +11 字段)

完整拼装步骤、坑、修法都在 ../doc/ 里:

  - ../doc/INCIDENT_2026-08-26_V21.md      🌟 v21.0 集成 haku_wrt 1.1.2 实机验证记录 (本次)

  - ../doc/RELEASE_2026-08-21_V17.md       v17.0 双频 WiFi + LuCI 25.12 + 实机冷启动验证

## 上手步骤 (v21.0)

1. **正常烧写 (智能识别当前分区,自动烧对侧 sys):**
   ```
   cd release/
   ./build.sh                # 默认烧 v21.0
   # 或 ./build.sh v22.0     # 指定别的版本
   # 烧完后等 90s 让新 sys 启动
   ssh root@10.11.12.1
   #   root 密码: nekoneko (预留空密码也支持, v15+ 修补)
   ```

2. **验证 haku_wrt 1.1.2 已就位:**
   ```
   ssh root@10.11.12.1 'grep version /etc/morden_web/config.json'
   # 期望: "version": "2026-08-26 ver1.1.2"
   ```

3. **LuCI + haku_wrt 验证:**
   ```
   # uhttpd :81 (LuCI)
   curl -kI https://10.11.12.1:81/cgi-bin/luci
   # haku_wrt :80 (Web 面板)
   curl -kI http://10.11.12.1/
   ```

4. **紧急 TFTP 救援 (砖了用):**
   ```
   # 串口接上, U-Boot 提示符下跑 release/flash-via-tftp.sh 输出的命令
   ```

5. **回退到上一个 sys 分区 (假设当前在 sys1 跑 v21.0,想回 sys2 跑 v20.6):**
   ```
   ssh root@10.11.12.1
   fw_setenv flag_boot_rootfs 1
   fw_setenv flag_try_sys1_failed 1
   fw_setenv flag_try_sys2_failed 0
   reboot
   ```
